# 📝 Flask Blog

## 📌 Описание

Flask Blog — это веб-приложение для ведения блога, где пользователи могут:

- создавать статьи;
- редактировать публикации;
- удалять записи;
- управлять контентом через удобный интерфейс.

---

## 🚀 Используемые технологии

- Python 3
- Flask
- SQLite
- HTML / CSS
- Flask-Login
